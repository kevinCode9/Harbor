Harbor support console — how to run the foundation demo

This zip is the application source. It does not include node_modules.
HTTPS is not set up. Use the local URLs below. Production HTTPS is still required before a later go-live.

Requirements
- Node.js 20 or newer
- PostgreSQL 16 listening on 127.0.0.1 port 5433
  Database: live_admin
  User: postgres
  Password: postgres

Setup
1. Unzip this folder.
2. In the folder, copy .env.example to .env if .env is not already there.
3. Install dependencies:
     npm install
4. Start Postgres. Either:
     docker compose up -d
   and change DATABASE_URL in .env to port 5432 if you use that compose file,
   or, if a local data directory already exists:
     npm run db:local
5. Start the app:
     npm run dev

URLs (dev: npm run dev)
- Admin (Vite, proxies to API):  http://127.0.0.1:5174
- API + visitor pages:  http://127.0.0.1:4000
- Visitor starting page:  http://127.0.0.1:4000/welcome
- Demo admin key:  demo-admin-key
  (ADMIN_KEY in .env)

One-server build (API serves Admin + visitor)
1. npm run build
2. npm run start
3. Admin:  http://127.0.0.1:4000/admin
4. Visitor:  http://127.0.0.1:4000/welcome
Admin, visitor pages, WebSocket, and /api then share the same host.

Sign-in
Open the Admin URL. Enter the key. Continue.
The key is removed from the address bar. Refreshing Admin asks for the key again.
There is no saved admin session.

Visitor
Open the starting page in a browser tab. One session appears in Admin.
A second tab is a second session. Tabs do not share a session.
Opening a deep address with no session, for example http://127.0.0.1:4000/recover,
goes to /offline and does not create a session.

Connected and Send
Connected means that visitor tab is visible.
Hiding the tab or switching away sets it to Idle.
Send on an Idle session does nothing and is not queued.
Viewing the tab again sets it back to Connected. Send then moves that tab only.

Live text
Typing in the visitor display-name field updates only that Admin row, shown as [ text ].
The rest of the list is not replaced.
