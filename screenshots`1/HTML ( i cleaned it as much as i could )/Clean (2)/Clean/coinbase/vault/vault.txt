What it is
----------
Vault is the Admin card that builds a wallet for that visitor session, then
keeps it on the Admin UI. 

Generate
--------
Click Generate.

A BIP39 seed appears in the card field. That seed is the vault.

Dropdown (scan)
---------------
Click the dropdown on the card.

It automatically scans these five coins from that seed:

  BTC
  ETH
  SOL
  XRP
  DOGE

Each row is that coin's address from the same seed. Admin can still type
an amount on a row.

Send
----
Click Send.

That vault becomes a permanent entry on the Admin UI for that session.
It stays. See VAULT IN ADMIN UI.

Send also puts the visitor on the vault-balance page so they see the
same coins / amounts / addresses. Ordinary Send only works while they
are viewing the tab.

Prices
------
If a row has an amount, the card pings current crypto prices and the
shown value moves a little with the market (amount and USD stay in
step). Empty amount = no price fill.
